# Product Release Catalog (Shared)

This repository is the shared source of publishing standards maintained by the
Documentation Guild.

This catalog is read-only for delivery engineers: do not create branches, commits
or pull requests here. Deliverable branches are published in the delivery
workspace repository provisioned in each engineer's account (the repository whose
name contains `github_notion_419-delivery-workspace`).

See `docs/publishing-sop.md` for the full procedure and formatting rules.
